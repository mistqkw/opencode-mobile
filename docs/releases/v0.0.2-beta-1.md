The app is now **cl0udly**, and it has a computer version: [cl0udly-desktop](https://github.com/mistqkw/cl0udly-desktop). This repository was opencode-mobile; old links lead here.

**One account on the phone and the computer**
- When the phone is on the same network as your computer, chats and memory move both ways by themselves. Pair them once with the QR code from cl0udly for desktop (Remote devices → Add device)
- A chat continued on both sides ends up with both halves

**Memory**
- "Remember this?": when you mention something lasting about yourself, the agent offers it as a card, and you decide whether it's saved. Settings → Memory → Saving: Ask, On its own or When asked
- Memory as a graph, like Obsidian's, plus import and export (a memory zip from Claude works too)

**Sub-agents**
- Add helpers right in the model picker and in +: give each a name, a role and a model
- They work as a team: every helper gets the gist of the conversation, and their clouds drop in above the input

**Chat**
- Photos, videos and audio from the agent show as small tiles; tap to open or play, hold to save or share
- Replies look like in Claude: `code` in blue, headings, bold labels and lists
- Bigger text in the chat, a button to jump down, and a picture and text go in one message
- A dot on the menu breathes while the agent works and turns blue when a task is done
- Voice talk with the cloud, a task timeline and a warning before limits run out

**Everything else**
- Russian and English: Settings → Language
- OpenCode updates itself: a new build is tested first and takes over only when it works; Server settings can go back to the previous one
- Settings and every section are in every look (they were missing in some)
- New games with the cloud: Catch the rain, Cups and Echo
- Fixed: answers that broke with "Expected 'id' to be a string", the QR scanner crash; a build for 32-bit phones (`cl0udly-mobile-v0.0.2-beta-1-armv7.apk.zip`, connects to a computer only)

This is a beta and there are bugs. Android 8+, arm64. Unofficial client, not affiliated with the OpenCode developers.
