A new look with a mascot that lives in the app, a team of agents, connecting to your computer by QR code and a calmer chat.

**cl0udly**
- A new default look: graphite, quiet pixel clouds in the background and a little pixel cloud on the home screen
- Tap it and it's happy, poke it a lot and it gets grumpy, hold it and it falls asleep. It watches the message field while you type
- While the agent works, the cloud acts it out: writes with a pen, reads a book, runs in the rain, searches with a magnifier, ticks off a plan
- The app is now called cl0udly, with a new icon (works with themed icons too) and a light version of it
- A pixel intro that hands the cloud over to the home screen
- A different greeting every time you open the app
- Anonymous chat: a see-through dashed cloud. Nothing is kept, and it's deleted when you leave
- Chats in the side menu get an icon by type (code, task, research, writing, talk) and show how many helpers worked in them

**The cloud is alive**
- Ten different reactions to a tap: hops, spins, dances, hums, sneezes, plays peekaboo and more
- Pet it and hearts float up; hold it and it falls asleep; flick it up and it jumps
- It reacts to the phone: shake it and it gets dizzy, turn it upside down and it panics, plug in the charger and it cheers, below 15 % it gets sleepy, and the first launch of the morning gets a stretch
- Holidays and seasons: a Santa hat, a witch hat with bats, confetti at New Year, snow, autumn leaves and more
- Its own room in the side menu: talk to it and play ping-pong against it while a task runs. The chat has a "Play with cl0udly while you wait" link
- Settings → cl0udly: turn each reaction on or off, pick an outfit by hand, see how many times you've petted it
- The assistant now introduces itself as cl0udly and still names the real model when asked. Can be turned off
- While the finger is on the mascot, the side menu stays put

**Welcome tour**
- The first launch is a short tour by the mascot, then your own settings (theme, icon, what it reacts to). The interface picker page is gone
- On Start the cloud invites you in and the screen dives into its eye

**Connect to your computer by QR code**
- Remote devices → Add device → Scan QR code. On the computer run one command (shown in the app). It starts OpenCode with a fresh password and prints a QR code
- If the computer has OpenCode 2.x or none at all, the script downloads 1.19.4 next to it without touching your setup
- Chats about code from this phone also show up in Remote devices → This phone

**Team of agents**
- Settings → Capabilities → Team
- My team: name your helpers, give each a role and a model. The main agent splits the task between them and runs them in parallel
- Automatic: pick a few models and a limit, the main agent decides how many helpers a task needs. Simple tasks get none
- While helpers work, the chat shows who is doing what. Tap one to see its session

**In the chat**
- Text and scrolling are smooth: no more jumping on every chunk or when a reply ends
- The agent's work looks like Claude Code: one summary line ("Ran 3 commands, edited count.sh +7 −1"), tap for a card of steps, tap a step for the command and its output, the diff or the thought
- Live terminal: command output shows up line by line while it runs
- Changes: Keep or Undo each file the agent edited
- Search now looks inside messages and memory, not only titles

**Also**
- Leaving the app for a moment brings you back to the same screen; a full close starts from home
- Faster screen transitions
- A reminder on the home screen if Android may stop long tasks in the background or notifications are off
- Settings → Report a bug opens a GitHub issue with the phone, version and server log filled in (passwords and keys removed)
- "Thinking" no longer has a star

This is a beta and there are bugs. Android 8+, arm64. Unofficial client, not affiliated with the OpenCode developers.
