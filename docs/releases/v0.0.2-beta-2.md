A bug-fix release with a new look.

**New look**
- A night sky with pixel clouds behind the chat, kept quiet so it doesn't get in the way; the interface around it is plain grey
- A new launch screen: stars, clouds drifting in, the cloud landing on them

**Menus and input**
- Menus and windows open right where you tap, as floating cards, instead of sliding up from the bottom
- The input has a thin frame and one button (voice, send, stop), grows smoothly up to 6 lines and folds back when the keyboard hides
- A draft is kept in every chat

**Chat**
- Code in replies: line numbers, highlighting, copy, save and preview
- Search finds words inside messages, whatever the letter case
- A deleted chat can be brought back, and errors say what to do
- The chat stays where you left it when you scroll up a little

**Fixed**
- The "OK" error and the used-up free limit with GitHub Copilot
- Broken replies from GPT-OSS

32-bit phones: `cl0udly-mobile-v0.0.2-beta-2-armv7.apk.zip` (connects to a computer only). Computer version: [cl0udly desktop 0.0.1 beta-2](https://github.com/mistqkw/cl0udly-desktop/releases/tag/v0.0.1-beta-2).

This is a beta and there are bugs. Android 8+, arm64. Unofficial client, not affiliated with the OpenCode developers.
