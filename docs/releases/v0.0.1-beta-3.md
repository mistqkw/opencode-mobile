Самое большое обновление: навыки, GitHub и агент, который умеет пользоваться телефоном.

Навыки
• набери / в чате — появится список навыков и команд
• перенеси свои навыки из Claude или ChatGPT: .zip, .skill или SKILL.md
• вставь инструкции своего GPT или проекта — получится навык
• или просто попроси в чате: «сделай навык для…», агент напишет его сам

GitHub
• входишь один раз кодом с GitHub
• агент клонирует, правит, коммитит, пушит и открывает PR от твоего имени
• никаких соавторов-ИИ в коммитах

Телефон
• агент ставит будильники и напоминания, читает и заполняет буфер обмена, делает фото, сохраняет файлы в «Загрузки»
• сайты, которые он собрал, открываются в превью прямо в приложении
• прогресс задачи на экране блокировки, кнопки «Разрешить / Запретить»
• «Поделиться → Ask OpenCode» из любого приложения

Ещё
• кружок расхода сверху: лимиты на 5 часов, неделю и месяц, что занимает контекст
• цена сообщения до отправки
• если сервер остановился посреди задачи — «Продолжить» или «Отменить»
• новый вид с шариком, которого можно тыкать
• первый запуск с выбором вида, иконки и доступа, вход в OpenCode Zen и Go
• обновления сами приходят из GitHub: «Установить» — и всё
• резервная копия всего одним файлом и перенос на другой телефон

Это бета: баги будут. Android 8+, arm64. Неофициальный клиент, к разработчикам OpenCode отношения не имеет.

Обновление с beta-2: просто установи APK поверх. Перенос с отладочной сборки — Settings → Backup & move.
