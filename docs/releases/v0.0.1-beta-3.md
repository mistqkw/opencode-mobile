The biggest update so far: skills, GitHub, and an agent that can use your phone.

**Skills**
- Type / in the chat to pick a skill or command
- Import the skills you use in Claude or ChatGPT: .zip, .skill or SKILL.md
- Paste the instructions of a custom GPT or a Claude project to turn them into a skill
- Or just ask in the chat: "make a skill that…", and the agent writes it

**GitHub**
- Sign in once with a code from GitHub
- The agent clones, edits, commits, pushes and opens PRs under your name
- No AI co-authors in commits

**Phone**
- The agent can set alarms and reminders, read and fill the clipboard, take a photo and save files to Downloads
- Sites it builds open in a preview inside the app
- Task progress on the lock screen, with Allow / Deny buttons
- Share → Ask OpenCode from any app

**Also new**
- Usage ring in the top bar: 5-hour, weekly and monthly limits, and what fills the context
- Estimated cost before you send a message
- If the server stops in the middle of a task: Continue or Cancel
- A new look with a little ball you can poke
- First launch with a choice of look, icon and permissions, and sign-in to OpenCode Zen and Go
- Updates now arrive from GitHub inside the app: tap Install and that's it
- Backup of everything in one file, to move to another phone

This is a beta and there are bugs. Android 8+, arm64. Unofficial client, not affiliated with the OpenCode developers.

Updating from beta-2: install this APK over it.
