Fixes: answers that broke with "Expected 'id' to be a string", the QR scanner crash, and a build for 32-bit phones.

**Fixed**
- "Expected 'id' to be a string" (#1). Pollinations and Copilot sometimes start a tool call without an id, and the whole answer failed. The app now passes their answers through a small fixer on the phone that fills the id in. Already set up providers are moved over by themselves
- Remote devices → Add device → Scan QR code no longer closes the app
- "Report a bug" shows the server state in words instead of a scrambled name

**32-bit phones (armv7)**
- OpenCode is made only for 64-bit phones, so a 32-bit phone can't run its own server
- For them there is a separate build, `opencode-mobile-v0.0.1-beta-5-armv7.apk.zip` (unzip and install). It skips the setup and goes straight to connecting a computer: Code → Remote devices
- 32-bit phones don't get updates inside the app, download new versions here

This is a beta and there are bugs. Android 8+, arm64 (armv7 only with a computer). Unofficial client, not affiliated with the OpenCode developers.
